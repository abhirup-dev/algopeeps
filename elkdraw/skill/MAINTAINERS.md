that way, and keep roadmap words ("not yet", task numbers) out of the
agent-facing files — say "not available" there, and put the reason and task

When a future task implements one of the still-stub tools (`export`, `wait`):
update its row here to "Built", then update `SKILL.md`'s Quick Reference /
Iterative Refinement / File I/O / Snapshots / Error Recovery sections and
`references/cheatsheet.md`'s "Scene" and "Not implemented" sections to move it
out of "not available" — the structure (headings, order) should stay the same
as `excalidraw-skill`'s, only the cell contents change. Also drop it from
`SURFACE.md`'s "still reject with `NOT_IMPLEMENTED`" list.

Deliberate differences from yctimlin's skill: no Step-0 auto-start and no
exit 4 (headless render); Quality has "The Loop" and a lint table instead of a
by-eye checklist; Arrow Routing moves shapes instead of bending arrows;
Mermaid, import, share, arrange and duplicate sections are one-liners;
`evals/evals.json` is not mirrored (the audit uses the dogfood tasks).
