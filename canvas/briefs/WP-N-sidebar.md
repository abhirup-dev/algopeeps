## Build

1. `sidebar/ThreadsSidebar.tsx`: an Excalidraw `<Sidebar name="threads" docked={docked} onDock={setDocked}>` with `Sidebar.Header` (title "Threads", the built-in dock button and close), `Sidebar.Tabs` with two tabs `open` and `all`. Body = a scrollable list region and a fixed footer region. Content is placeholder for now: render `props.items: SidebarItem[]` where `SidebarItem = {id, index: number, title, subtitle?, status: "open"|"resolved"|"detached", unread?: boolean, lines: {author:"human"|"agent", text, ts}[]}`; each item is a collapsible row (index badge, title, status pill, last line preview when collapsed, full lines when expanded). Footer: a `Comment on selection` button that is disabled unless `props.selectionCount > 0`, and calls `props.onComment()`; a `filter` state that switches tabs. Clicking a row calls `props.onFocus(id)`. All styling in `sidebar/sidebar.css`; use Excalidraw's CSS variables (`--color-primary`, `--island-bg-color`, `--default-border-color`, `--text-primary-color`) so dark mode works. Agent lines in `#9c36b5`.
2. Wire into `CanvasApp.tsx` behind minimal edits: pass `items={[]}` for now (an exported `SAMPLE_ITEMS` array in `sidebar/sample.ts` is used by the dev page and the Playwright test only), `selectionCount` from `appState.selectedElementIds` in the existing `onChange`, `onComment`/`onFocus` as no-op console logs. Add a `Threads` toggle button in `renderTopRightUI` that calls `excalidrawAPI.toggleSidebar({name:"threads"})`. Default: sidebar closed, `docked` remembered in `localStorage["canvas.threads.docked"]`.
3. Badges: `sidebar/Badges.tsx` renders, for each item with `props.targets: Record<id, {x,y,w,h}>` (scene coords; caller supplies), a 20 px numbered circle at the bbox top-right via the same scene→viewport conversion WP-M used (`(x + scrollX) * zoom`), repositioned on `onChange` + `onScrollChange` with rAF coalescing. Click → `onFocus(id)`. `pointer-events:auto` on badges only. In WP-N the caller passes `{}` except in the dev page.
4. Dev page: `?sidebar=1` shows the sidebar open and docked with `SAMPLE_ITEMS` (3 items: open unread, open, resolved) and two fake target rects so badges ①② are visible.
5. Playwright `sidebar.spec.ts`: dev page → sidebar visible → 3 rows → click row 1 expands → `Comment on selection` disabled → tab `all` shows 3, tab `open` shows 2 → badges ① ② present.
6. Keep the bundle < 5.2 MB; rebuild `app/dist/canvas.html`.
